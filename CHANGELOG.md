# Changelog

All notable changes to GeoInvLab3D are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows Semantic Versioning.

## [0.1.0] - 2026-09-17

### Added

- Initial release of GeoInvLab3D.
- Modular Python framework for three-dimensional geophysical forward modeling and inversion.
- Core data structures for meshes, models, and geophysical observations.
- Gravity modeling and inversion capabilities.
- Magnetic modeling and inversion capabilities.
- Three-dimensional magnetotelluric (MT) forward modeling and inversion capabilities.
- Gauss–Newton inversion framework with L2 regularization.
- Model and mesh input/output functionality.
- Three-dimensional visualization tools.
- Graphical user interface based on PySide6.
- Synthetic examples for gravity, magnetic, and magnetotelluric methods.
- Automated test suite covering core components and geophysical methods.
- User manual in HTML and PDF formats.
- Installation and package configuration using `pyproject.toml`.

### Documentation

- Added project README.
- Added GeoInvLab3D User Manual.
- Added synthetic modeling and inversion examples.

### Testing

- Added automated tests for core data structures, forward operators, inversion procedures, and geophysical methods.
