Magnetic Workflow

The Magnetic method estimates subsurface magnetic-susceptibility variations from magnetic observations.

  1. Import magnetic observations using a supported data file.
  2. Select Magnetic in the Inversion method selector.
  3. Create or load the structured mesh.
  4. Create or load a magnetic-susceptibility model. The GUI displays the parameter unit as SI.
  5. Configure and run the inversion.
  6. Inspect the inversion result and display the project in 3-D when the optional viewer is available.
Check the magnetic data component, coordinate system, units, and susceptibility convention expected by the selected forward operator before interpreting a result.
