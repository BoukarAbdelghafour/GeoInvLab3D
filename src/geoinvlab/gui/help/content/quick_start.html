Quick Start

  1. Start the application. Install the GUI extra and launch geoinvlab3d or run the GUI entry point from the development environment.
  2. Create or open a project. Use File → New Project or File → Open Project.
  3. Import observations. Select File → Import Data or the Import Data button. The file dialog accepts CSV, TXT, DAT, and XYZ files.
  4. Select the method. In the Inversion tab, choose Gravity, MT, or Magnetic.
  5. Create or load a mesh. Use Mesh → Create Mesh or Mesh → Load Mesh.
  6. Create or load a model. Use the Model menu to create a model, load a model, or create a reference model.
  7. Configure inversion. Set the method and inversion parameters in the Inversion tab or via Inversion → Configure Inversion.
  8. Run inversion. Select Run Inversion. The interface reports errors in a message dialog and updates project/result information when successful.
  9. Inspect and save. Review the Data Table, Mesh, Model, Inversion, Properties, and 3D View areas. Save the project.
The order matters: import observations before creating a mesh through the GUI. A mesh replacement may clear the current model, reference model, and inversion result.
