Magnetotelluric (MT) Workflow

The MT method uses frequency-dependent electromagnetic observations and estimates electrical resistivity.

  1. Import an MT dataset in a supported file format. The interface recognizes station locations, frequencies, apparent-resistivity components, and phase components.
  2. Select MT in the Inversion method selector.
  3. Create or load a structured mesh.
  4. Create or load a resistivity model. The GUI displays the parameter unit as ohm·m.
  5. Configure the inversion and run it.
  6. Inspect the scalar MT component rows in the Data Table and review the inversion result.

MT data table

Each station-frequency observation is represented by eight scalar components: rho_xx, rho_xy, rho_yx, rho_yy, phase_xx, phase_xy, phase_yx, and phase_yy. If uncertainties are available, an uncertainty column is also displayed.

The MT table expands each station-frequency observation into eight rows for display. This is a presentation layout; it does not mean that the input file must contain eight separate records per observation.
