GeoInvLab3D User Manual

Version 0.1.0 · 3-D Geophysical Modeling and Inversion

GeoInvLab3D is a modular Python framework with a graphical interface for organizing geophysical data, defining a 3-D mesh and physical-property model, configuring an inversion, and inspecting project information and 3-D views.

Supported methods in the GUI: Gravity, Magnetic, and Magnetotelluric (MT).

Main interface

The main window contains a project panel, a central tab area, and a properties panel. The central tabs are Data Table, 3D View, Mesh, Model, and Inversion.

The menu bar provides File, Project, Data, Mesh, Model, Inversion, View, and Help commands. The Help menu opens this offline manual; press F1 to open it.

Project contents

A project can contain an imported geophysical dataset, a structured mesh, a physical-property model, a reference model when configured, inversion settings, and an inversion result. Use File → Save Project to save the current project as a GeoInvLab3D project file.

Scope note: This manual documents controls and workflows visible in the supplied GeoInvLab3D 0.1.0 GUI source. Exact solver options, file-column validation rules, and method-specific numerical assumptions should be checked against the corresponding API and data-loader documentation.
