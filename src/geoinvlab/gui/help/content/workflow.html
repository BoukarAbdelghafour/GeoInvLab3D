General Workflow

1. Project management

Create a new project, open an existing GeoInvLab3D project, and save the current project using the File menu. The project panel summarizes the project components and provides shortcuts to common operations.

2. Data import and inspection

Use Import Data to load observations. Imported observations are displayed in the Data Table. Classical gravity and magnetic datasets are shown with location, value, and uncertainty columns. MT observations are expanded into component rows, with location, frequency, component, value, and optional uncertainty.

3. Mesh definition

Create a structured 3-D mesh by specifying cell counts and cell dimensions, or load a mesh from a supported mesh file. The Mesh tab displays mesh information. Replacing an existing mesh can invalidate models and results tied to the previous mesh.

4. Physical-property model

Create a model on the active mesh, load a model, or create a reference model. The model parameter depends on the selected method: density for gravity, electrical resistivity for MT, and magnetic susceptibility for magnetic inversion.

5. Inversion configuration and execution

Select the method, configure regularization and solver settings using the inversion dialog, and run the inversion. The interface displays the current configuration and available result properties.

6. Visualization and project persistence

Use View → Show Project in 3D to display available project objects when the optional 3-D viewer is installed. Save the project after important changes.
