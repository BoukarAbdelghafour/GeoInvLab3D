Data File Formats

Import dialog

The GUI file picker lists *.csv, *.txt, *.dat, and *.xyz data files, as well as an All Files option. Actual accepted columns and validation are determined by the data importer and dataset classes.

Classical data export

For gravity and magnetic datasets, the GUI exports location coordinates and the data value. If uncertainties are present, an additional uncertainty column is written.

FieldDescription
x, y, zObservation coordinates
valueObserved scalar value
uncertaintyOptional uncertainty for the observation

MT data export

MT export writes one row per station-frequency observation. The base columns are coordinates, frequency, four apparent-resistivity tensor components, and four phase tensor components. When uncertainties are present, eight additional uncertainty columns are written.

x,y,z,frequency,rho_xx,rho_xy,rho_yx,rho_yy,phase_xx,phase_xy,phase_yx,phase_yy

Optional uncertainty columns are named unc_rho_xx, unc_rho_xy, unc_rho_yx, unc_rho_yy, unc_phase_xx, unc_phase_xy, unc_phase_yx, and unc_phase_yy.

Project files

The GUI saves and opens GeoInvLab3D project files with the .json extension. These are project files, distinct from observation data files.

The source provided for this integration does not define the complete mesh/model ASCII schemas. Consult the corresponding load_mesh, load_model, and data-importer documentation for exact column order, headers, coordinate units, and validation rules.
