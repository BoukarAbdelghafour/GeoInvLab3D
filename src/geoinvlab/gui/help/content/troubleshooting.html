Troubleshooting

The GUI does not start

Confirm that the GUI extra is installed in the active Python environment. Run python -m pip show PySide6 and verify that the geoinvlab3d command is installed in that same environment.

The 3-D viewer is unavailable

The 3-D viewer is optional. Install the visualization extra, including PyVista and PyVistaQt, in the same environment as GeoInvLab3D. The main GUI can display a message when the optional viewer cannot be initialized.

Data import fails

  • Check that the selected file is readable text data.
  • Verify that the columns and units match the data importer requirements.
  • Check for missing values, non-numeric values in numeric columns, or inconsistent row lengths.
  • For MT data, verify that frequencies and the required tensor components are present.

Mesh or model operations fail

Ensure that a dataset has been imported before creating a mesh through the GUI. Ensure that a model is compatible with the active mesh. If replacing a mesh, remember that dependent models and results may be cleared.

Inversion fails

Check that the selected method matches the imported dataset, that a mesh and suitable model are available, and that inversion parameters are valid. Read the full error message displayed by the application.

3-D display fails

Confirm that the visualization dependencies are installed and that the project contains objects supported by the viewer. Use View → Reset 3D View if the camera state is unsuitable.
